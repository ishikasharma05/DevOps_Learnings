# System Health Monitor

## What This Does
This script automates system health monitoring by checking CPU usage, 
RAM usage, disk usage, and currently running processes. Instead of 
manually checking each resource, it generates a complete health report 
instantly and alerts you when any resource exceeds safe thresholds.

## Prerequisites
```bash
pip install psutil
```

## How to Run
```bash
python "Linux System Health Monitor.py"
```
