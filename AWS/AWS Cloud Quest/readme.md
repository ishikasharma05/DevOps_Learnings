One AWS service I understood well

Amazon EC2 (Elastic Compute Cloud)

Through the Cloud Quest labs, I gained a solid understanding of Amazon EC2. I learned how to launch instances, connect using SSH, configure security groups, install software like NGINX, and host a static portfolio website. I also understood how instance types affect both performance and pricing.

One service I found challenging

Amazon EFS (Elastic File System)

Amazon EFS was the most challenging service for me. I had to configure mount targets, create the correct security group with NFS (port 2049), and mount the file system on an EC2 instance. Troubleshooting issues such as missing mount points, security group configuration, and ensuring the EC2 instance could communicate with the EFS file system helped me better understand how AWS networking and permissions work together.

One real-world use case for AWS

A real-world use case for AWS is hosting and scaling a company's web application. For example, an e-commerce company can host its website on Amazon EC2, store product images in Amazon S3, use Amazon EFS for shared application files, secure access with IAM and Security Groups, and monitor costs using the AWS Pricing Calculator and AWS Budgets. This allows the application to remain secure, highly available, and scalable as customer traffic grows.
